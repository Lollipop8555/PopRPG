# PopRPG 设计文档 — 模块：视觉风格（全局基调）

> **本模块从原 DESIGN.md §10 抽出并前置到文档最前排。** 视觉风格是**全局基调**，不是收尾才考虑的事——任何 UI（构建页、游玩页、属性面板、按钮、网格、地图组件、弹层）都必须从一开始遵循「纸张 + 手绘 + 涂鸦」观感。AI 开工任何界面任务前，**先读本文件并贯穿实现始终**，不要等 Phase C 才补。

## 视觉风格（纸张 + 手绘）[原 §10]

- **整体基调**：暖色纸张（米黄 / 羊皮纸），模拟纸纹与手绘。
- **纸纹**：内联 SVG `feTurbulence` 噪声滤镜做颗粒质感（data URI 背景），叠加轻微暖色渐变；无需外部图片资源。
- **手绘线条**：边框 / 分隔 / 网格线用 SVG 位移滤镜（`feTurbulence` + `feDisplacementMap`）做出轻微抖动的不规则手绘感；或 CSS 不规则 `border-radius` + 微小旋转。避免引入 rough.js 等额外库（除非后续确认）。
- **字体**：标题 / 正文用手写体；拉丁文用 Caveat / Patrick Hand 类，中文用手写体（如马善政 / 龙藏 / 字芒行等），自托管。
- **图标**：lucide 矢量图标可套同一手绘滤镜柔化；自定义 / 内容继续用 Emoji。
- **网格**：构建态网格线呈手绘铅笔线，每 10 格加粗且略带颜色深浅变化；游玩态去网格、留细坐标参照线（同样手绘风）。
- **起点 / 终点的图形（不用 emoji 占位）**：
  - **起点 = 手绘三角旗**：一支旗杆 + 一面边缘微鼓的三角旗面，暖红填充、深棕描边，底下带一小笔土坡。
  - **终点 = 藏宝图手绘 X**：两笔交叉的圆头粗描线，暗红描边，外面一圈虚线提示。
  - 二者均为 **SVG path**，套全局手绘滤镜（`feTurbulence + feDisplacementMap`，id `poprpg-sketch`），
    随缩放同步放大；**不使用 emoji**，也不用外部绘图库。构建页画布与游玩页地图共用同一份组件（`src/ui/Marker.tsx`）。
- **组件放置**：地图上的建筑 / 怪物以"贴在纸上的手绘便签 / 涂鸦"观感呈现（轻微阴影 + 不规则边）。
- **交互手绘反馈（建议，非必须）**：拖拽时便签轻微倾斜、点击有手绘描边高亮、放置落定有"贴纸"动画，使操作也有涂鸦感。
