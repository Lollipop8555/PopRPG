## 一、渲染目标

游玩态的地图是一块**连续画布**：被采用的背景图铺在底层，道路上叠贴图与标记。本节只定义**背景图与地图坐标的对齐关系**、**多地图（多层级）的适配方式**，以及图片边界之外露出的填充色。

素材缺位时回退为程序绘制的纸面底纹（[`../skin.md`](../skin.md) §一）。

## 二、字段

`background` 是**数组**（裁决 8；语义以裁决 23 为准）：一张皮肤可携带多套背景，**数组下标即地图下标**——第 `i` 张地图（pmod `maps` 的下标 `i`，从 0 起）用 `background[i]`，**不需要任何匹配 key**。

```json
"background": [
  { "img": "resource/bg/plain.jpg", "cellSize": 25, "startX": 256, "startY": 256, "color": "#F2ECDD" },
  { "img": "resource/bg/cave.jpg", "cellSize": 25, "startX": 200, "startY": 200, "color": "#3A352C" }
]
```

上例皮肤背景长度 2，而 pmod 有 4 张地图，取值结果为（**每张地图只渲染一层**）：第 1、2 张地图（下标 0 / 1）分别用 `plain.jpg` / `cave.jpg`；第 3、4 张地图（下标 2 / 3）**越界 → 降级为使用最后一张（下标 1）**，即同样是 `cave.jpg`。填充色各随其层：第 1 张地图用 `#F2ECDD`，第 2～4 张地图用 `#3A352C`（第 3、4 张虽因越界落到下标 1，取到的也是**该层自己的** `color`；若下标 1 漏写 `color`，则这 3 张地图一律用**全局主题色**，而不会去蹭下标 0 的 `#F2ECDD`）。

| 字段 | 类型 | 含义 | 缺省 |
|---|---|---|---|
| `img` | 字符串 | 背景图，路径**相对包根**（`resource/bg/cave.jpg`，[`00-package.md`](00-package.md) §2.2） | 无（该项不绘制） |
| `cellSize` | 正整数 | **背景图上一个游戏格占多少像素**，把地图坐标换算到图片坐标；**同时也是道路等地图层素材的出图基准**（§3.1） | 无（该项不绘制） |
| `startX` | 整数 | 图片上该点与地图格 `[0,0]` 的**中心**对齐（横向） | 无 |
| `startY` | 整数 | 同上（纵向） | 无 |
| `color` | 颜色 | **图片边界之外**的填充色，避免边缘穿帮；**每个层级各自携带**，取**实际被采用的那一层**的值；该层没写 `color` 时**直接降级为全局主题颜色**，**不向上层回退找色**（校验项 `KB-8`）——因此**每层都要求显式写出 `color`** | 全局主题色（纸面底色） |

**取值规则（裁决 23，修订裁决 17）**：背景**不做叠加**——**每次只取一层渲染**，且**不需要任何匹配 key**，纯按数组下标对应：

1. **下标匹配**：第 `i` 张地图（`i` 从 `0` 起）取 `background[i]`；
2. **越界降级**：`i` 超出数组长度（`i ≥ 数组长度`）时，**降级为使用最后一张** `background[数组长度 − 1]`（上例第 3、4 张地图都用下标 1 的图）；
3. **每张地图只绘制这一层**，命中即停，不再叠加；该层素材不可用时（`img` / `cellSize` 缺失或路径取不到，`KB-1` / `KB-2`）按「没有则降级到上一层」继续向**更靠前的层**回退（`i−1`, `i−2`, …）；
4. `background` 缺失、为空数组，或全部层都不可用 → 本节视为**未接管**，按皮肤整体优先级继续降级（本局 `.pp` → 用户全局 pp → 程序绘制），全部落空即**再次降级为默认配置**——程序绘制的纸面底纹（[`../skin.md`](../skin.md) §一、[`00-package.md`](00-package.md) §4.1）；
5. **颜色不降级**：`color` 是**该层自身的属性**、随层一并被采用——被采用的层写了 `color` 就用它；**没写就直接用全局主题颜色**（纸面底色），**不会**沿 `i−1` / `i−2` 回退去找上层的 `color`。故**每层都要求显式写出 `color`**（校验项 `KB-8`）。

因此最常用的写法是**只写一层**（所有地图共用同一背景）；需要逐图区分时按 pmod 的地图顺序依次补齐，**pmod 新增地图无需改动皮肤**（超出部分自动落到最后一层）。

> **边界约定**：本节的 `color` 是**画布级**（图片之外的填充），[`06-item-building.md`](06-item-building.md) 的 `background` 是**组件级**（图标／格子衬底）。两者同名但层级不同，**画布级保留 `color` 原名**（裁决 3 未采纳改为 `outsideColor`），组件级则升级为 `{ fill, stroke, img }` 三元组以示区别。

### 2.1 由 `{}` 升级为 `[{},{}]` 的兼容写法（裁决 8）

- 只写一个对象（`"background": { ... }`）时，视为**单元素数组**（单层）：所有地图都取它（越界也落到它，因为它是最后一层）；其 `color` 若漏写，所有地图一律用**全局主题色**。
- 写成数组时，第 `i` 张地图取 `background[i]`；**数组比地图短时，超出的地图统一用最后一层**——这覆盖了升级前的全部用法。
- 判定「某张地图是否有可用背景」的检查见 `KB-6`（无可用层 → 降级为默认配置）。

### 2.2 改名决议

| 原字段 | 决议 | 说明 |
|---|---|---|
| `dpi` | **采纳 `cellSize`** | 原字段实际语义是「每格像素数」，与 `dpi` 的通行含义（每英寸点数）无关 |
| `color` | **保留原名** | 见 §二 边界约定；组件级另用三元组区分。**语义收紧为「每层自带」**：采用层写谁就是谁，漏写即全局主题色，**不沿层级回退链找色** |
| 数组语义 | **多层叠加 → 按下标一一对应、单层渲染**（裁决 23 修订裁决 17） | **无匹配 key**：第 `i` 张地图用 `background[i]`，越界降级为最后一层；**只绘制该层**；`color` **随采用层一并生效**（只降图不降色） |

## 三、坐标映射（规范定义）

地图格坐标以 `[0,0]` 为原点、`col` 向右、`row` 向下，单位是**格**。

```
图片坐标点 (startX, startY)  ≡  地图格 [0,0] 的中心
格 [col, row] 的中心像素      =  (startX + col × cellSize, startY + row × cellSize)
地图像素原点（格 [0,0] 左上）  =  (startX − cellSize ÷ 2, startY − cellSize ÷ 2)
```

- 原始需求「采用中心对齐的方式」与「图片此位置与 [0,0] 对齐」两句互相冲突（既说中心对齐、又说指定点对齐）。裁决为：**指定的图片点 = 格 `[0,0]` 的中心**，统一为前式。
- **负格坐标合法**：`col < 0` 或 `row < 0` 的格子落在图片左上之外，按 `color` 填充。
- **缩放**：图片按 `屏幕每格像素 ÷ cellSize` 等比缩放后绘制（即 `cellSize` 个图片像素显示为 1 格）。`cellSize` 只影响清晰度与对齐，不改变格数语义。

### 3.1 与地图层素材的共同基准（裁决 3）

- **道路贴图与其它地图层素材的出图基准同样是 `cellSize`**，显示倍率同为 `屏幕每格像素 ÷ cellSize`，与背景图共用同一个坐标变换。
- 由此得到「素材与背景严格对齐、且缩放倍率一致（要么一起清晰、要么一起模糊）」的效果——这正是「道路贴图为了适配背景」的含义。
- **道路贴图不设背景色**：素材的透明区透出背景图，道路节不提供任何颜色／填充字段（[`01-road.md`](01-road.md) §五）。
- 若未配置背景（无 `cellSize`），地图层素材回退为按屏幕 `CELL` 出图（即纯屏幕像素基准）。

## 四、绘制顺序

```
① color 填充（画布全域，兜住图片之外；取**被采用层**的 `color`，该层漏写则用全局主题色）
② 背景层（**只绘制被采用的那一层**：第 `i` 张地图取 `background[i]`，越界取最后一层，按 §三 缩放与偏移放置）
③ 参照线 → 道路贴图 → 建筑节点 → 标记 → 角色
```

- 背景图**不套手绘滤镜**（[`04-misc.md`](04-misc.md) §六）。
- 背景图**不参与点击命中**（不作交互层）。

## 五、校验项（构建页／Creative 模式「清单」，提示不阻断导出）

| 编号 | 检查 | 提示 |
|---|---|---|
| KB-1 | `cellSize` 缺省或 ≤ 0 | 无法对齐，该项不绘制 |
| KB-2 | `img` 路径在包内不存在 | 该项不绘制 |
| KB-3 | `startX` / `startY` 落在图片之外 | 图片与地图完全错位，需重新标定 |
| KB-4 | 背景图覆盖不到整张地图 | 边缘将露出 `color` 填充色，提示可接受或补图 |
| KB-5 | 背景图分辨率低于 `地图格数 × cellSize` | 放大后模糊，提示提高分辨率 |
| KB-6 | 某张地图**没有任何可用背景**（`background` 缺失／为空／采用层与回退链全部不可用） | 该地图降级为**默认配置**（程序绘制的纸面底纹），无需补图 |
| KB-7 | `background` 层数**多于** pmod 地图数 | 末尾若干层**永远不会被采用**（没有对应地图），提示删掉或确认是为后续地图预留 |
| KB-8 | **被采用的那一层**没有写 `color`（含越界降级后落到的那一层） | 该地图图片之外**直接露出全局主题色**——`color` 不做层级回退、不会去取上层的值；提示为该层补写 `color` |
| KB-9 | **相邻下标的两层**（相邻地图各取其一）`cellSize` / `startX` / `startY` 不一致 | 切换到相邻地图时背景会**跳变**，提示统一基准 |

## 六、取舍登记

| 编号 | 取舍 | 后果 |
|---|---|---|
| S-7 | 每层背景仍是**单张整图**，不做分块 / 多分辨率切换 | 大地图需要超高分辨率单图，体积与内存随地图面积平方增长 |
| S-8 | 背景图跟随 `cellSize` 缩放，不提供「按屏幕像素」模式 | 换设备（不同 DPR）时清晰度变化，需美术按最大目标分辨率出图 |
| S-19 | 背景**每次只渲染一层**（按下标取一层），不提供混合模式与 `opacity` 字段；`color` **每层各自声明、不做层级回退** | 同一张地图内无法叠加地形 ＋ 光影等多张图，需美术在**单图内合成**；相邻地图两层基准不统一会跳变（`KB-9`），`color` 未逐层写齐时填充色也会跳变（`KB-8`） |

## 八、实现落点（2026-09-30）

- **取层与落位**（[`canvas.ts`](../../../src/engine/skin/canvas.ts)）：`backgroundLayers()` 归一单对象／数组两种写法；`backgroundUsable()` 收紧到「有 `img` ＋ 正的 `cellSize`」（即 `KB-1`）；`backgroundOf(bg, mapIndex, available?)` 落 §二 的三条规则——**下标量出越界即 clamp 到最后一层**、采用层不可用即**向前回退**、一路落空即整节未接管；其中「路径取不到」（`KB-2`）由调用方经 `available` 传入（构建期用素材源 `has()`，**只问包里有没有、不建地址**）。`backgroundPlacement()` 出 §三 的缩放倍率与图片左上角落点，`startX` / `startY` 缺省按 `0`。
- **渲染**（[`src/play/MapView.tsx`](../../../src/play/MapView.tsx)）：底纹 `<rect>` 的 `fill` 取**采用层**的 `color`（漏写即 `var(--paper-card)`），紧跟着把背景图放进 `translate(x y) scale(s)` 的 `<g>`（`data-bg-layer` 便于核对取的是下标几），之后才是参照线 / 道路（§四 的 ①②③ 顺序）。
- **图片尺寸交给素材自身像素**：`background` 没有「多大一个盒」，故取图盒用 `w/h: 'auto'`（[`texture.ts`](../../../src/engine/skin/texture.ts)），SVG 层据此**不写 `width` / `height`**，由浏览器按 SVG2 的 auto 取素材原始像素——**无需解码图片量尺寸**；`auto` 盒量不出盒心，故该类元素不参与旋转 / 镜像（`background` 本来也没有 `rotate` / `flip`）。
- **§3.1 的共同基准已是现状**：屏幕上一格恒为 `MapView` 的 `CELL`，素材按 `cellSize` 出品、被拉伸进**一个屏幕格**，其倍率恰好就是「屏幕每格像素 ÷ `cellSize`」，与背景图共用同一个变换（[`01-road.md`](01-road.md) §十一）——故道路侧无需另算基准；未配背景时两者同值。
- **构建页画布**（`src/build/Canvas.tsx`）尚未接入，仍画纸面底纹。
