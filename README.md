# PopRPG

一个**单人跑团（Solo TTRPG）** Web 应用：自己画图、自己设定剧情、自己玩。

核心理念是 **"预设套件 + 随机揭晓"**——你摆下宝箱屋却不知道里面是药水还是空的，靠骰子与奖励池制造惊喜，把"自己画自己玩"的传统跑团乐趣和随机性结合起来。

- 跨端：手机 + 电脑（响应式）
- 分享：整套场景导出为单个 `.pmod` 文件（内部 Markdown），可读、可再编辑、可分享

## 两大阶段

- **构建（Build）**：像思维导图工具，左侧分组面板拖放组件（背景 / 怪物 / 道具 / 建筑 / 道路 / 职业），在方格地图上按格摆位、设定数值区间。
- **游玩（Play）**：消费构建结果，去网格线、只留坐标参照，按格正交移动、掷骰、揭晓随机奖励，跑通一场冒险。

## 技术栈

React + TypeScript + Vite · Zustand（状态）· lucide-react + Emoji（图标）· Markdown（`散文正文 + ```` ```yaml ```` 围栏，见 `docs/DESIGN.md`）· localStorage（本地单项目保存）。
