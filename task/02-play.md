## B0 游玩页框架与加载（§7.0 / §7.1）

- [ ] 路由：`/`（默认）= 游玩页；`/build` = 构建页（决策 1）
- [ ] 游玩页加载 `.pmod`：本地库匹配 / 文件导入 / 示例工程；无工程时引导去 `/build` 或选示例
- [ ] 去网格线、留每 10 格坐标参照线（§7.1）
- [ ] 游玩态 store：玩家状态(属性/技能栏/背包/穿戴/加点/剩余点/位置/身上状态) 进 `.psave`，不进 `.pmod`（§7.3）

## B1 开局流程（§4.2 / §7.1，决策 8）

- [ ] 职业：`rules.class_pool` 给出可选职业卡片，玩家手选（>1 时可自愿「掷骰决定出身」）；属性以 `base_stats` 起步
- [ ] 加点界面：6 属性各"+"、显示剩余自由点（`free_points`）；**随时可加**（战斗内外都可）；**无重置按钮**（不可洗点）；余点保留
- [ ] 点数持续进账：打赢/开箱 `point_reward` 加到剩余自由点（§4.8.8）
- [ ] 开局技能栏：**默认模板 = `['basic_attack','basic_magic']`**（cost 空）；**作者删/改时按 `.pmod` 实际**（决策 8）
- [ ] 开局家当：按 `starting_items` 塞背包（道具不是本事）；技能书也只是道具

## B2 网格移动与回合循环（§4.8.4 / §4.8.0，决策 6）

- [ ] 硬规则：正交四邻、不可斜走、可原路返回
- [ ] 回合制主循环：**回合【开始】先判存活、再 tick 一次**（决策 6）；移动掷 `rules.move.dice` 得 N 步 → 一次走完（中途可停）→ 走完算一个回合
- [ ] 每格：权限检查(`canPass`) → 扣消耗(`cost`) → 结算该格（建筑遭遇）
- [ ] **使用道具不占回合、不 tick**（随时可用，中毒扣到0仍能先吃药救活，决策 6）

## B3 战斗引擎与 UI（§4.8.3，决策 3/4/5）

- [ ] **交锋两回合结构（决策 3）**：
  - ① 玩家攻击回合：玩家【点攻击】(UI 等待，无倒计时) → 引擎 `atk_roll` + 怪物电脑 `def_roll` → 判定/作用/挂 effects；**落空仅本次不生效，仍进反击**（决策 4）；**命中致死→怪物即时败北，交锋结束不进反击**（决策 5）
  - ② 怪物反击回合（换防）：怪物电脑 `pick_dice` 选技能(按决策 9 回退) + `atk_roll`；玩家【点"防御"或主动选"不防御"】(决策 12)；防御→引擎 `def_roll`，不防御→固有数值；判定/作用/挂 effects
- [ ] 整次交锋 = 一个回合（tick 已在回合开始做过，结束不再 tick）
- [ ] 怪物死亡即时；玩家死亡延迟（回合开始才判）
- [ ] 战斗 UI：技能栏（cost 不足置灰）、攻击/防御按钮、当前 hp/mp、敌方信息

## B4 骰子系统与上屏公示（§7.2）

- [ ] 骰子类型全（d4/d6/d8/d10/d12/d20/d100）；组件自带合适骰子
- [ ] **所有"电脑掷骰"（怪物 atk/def/pick）结果必须在战斗 UI 公示**（玩家看到怪物掷了什么、为何这么打）
- [ ] 力值链五环明细展示：`怪物物攻[2~4]→掷1D6=5→4(本场固定)`、`本力值=...×职业%...+骰子→值`、`玩家物防=分配5→5`、`命中(值≥防)，伤害=max(1,...)`
- [ ] `target:self` 另写一条线（治疗术回自身）；法术显示 `mp` 流水（消耗3剩2）
- [ ] 道具不占回合，UI 用另一种颜色标出
- [ ] 掷骰历史可回放；转盘/幸运转盘点击投掷

## B5 技能施放交互（§4.8.3，复用 A8 `resolveSkill`）

- [ ] 选技能前先查 `cost`（不够置灰，§4.8.3）；够则扣再结算
- [ ] 6 步流程接 UI：选→查cost→算本力值→判定(`self`/`vs:none`跳过)→作用→仅命中执行 effects
- [ ] `target:self` 不对抗不落空仍掷骰（骰子定量）
- [ ] 学技能：读技能书/事件教/商店买 → 技能进栏(永久) 存 `.psave`；`forget_skill` 拿走

## B6 状态 / buff 结算与展示（§4.8.10，决策 6）

- [ ] 每回合【开始】先判存活再 tick：`duration−1`、按 `per_turn` 增减、按 `modifiers` 进力值链、归零移除
- [ ] **本回合刚挂状态到下回合开始才首次 tick**（决策 6 基石）
- [ ] 状态 tag 进能力集合（御火符顶火抗、力量祝福顶物攻+2）
- [ ] 状态 UI：图标/剩余回合/可解毒剂解

## B7 建筑遭遇交互（§4.8.5 / §4.8.9 / §4.8.11；**对话见 Phase E** [`05-npc.md`](./05-npc.md)）

- [ ] 踩 `building`：`treasure`→按 `rules.treasure` 掷定件数/份数揭晓；`monster`→`resolveMonster` 抽怪摇属性再打（决策 2）；`event`→§4.8.9；`shop`→§4.8.11；`mimic`→先按 `chance` 判定伪装；**（Phase E）`talk`→按实例 `npcs` / `dialog` 两级各掷一次 `talk.dice` 抽人 / 抽方案，进入对话弹层（§4.9，见 [`05-npc.md`](./05-npc.md) E4）**
- [ ] 战利品：战斗胜利按 `rules.loot` 抽（池取怪物 `reward_pool`，可权重）

## B8 商店 / 事件 / 战利品 UI（§4.8.9 / §4.8.11）

- [ ] 事件：查 `gate`(不满足按 `on_missing`)→`check` 判定(复用力值链)→`on_success`/`on_fail`(文本/扣资源/给点/给道具/挂状态)；必成/必败提示
- [ ] 商店：按 `stock` 上架→每件 `price` 掷定→玩家用 `currency` 指的那件道具付款（`payAndTake`）
- [ ] 战利品/奖励结果揭晓动画 + 入背包

## B9 装备穿戴 / 消耗品 / 背包（§4.2.4 / §4.3）

- [ ] 装备穿戴（多槽/挤占规则）：`modifiers` 进力值链②；标签进 capabilities
- [ ] 消耗品在对战/前进时使用（红瓶回 hp、蓝瓶回 mp）；随时用不占回合
- [ ] 背包：拾取按 `{id,count}` 条目数查 `inventory_size`（同种占1格）；满则拒绝提示

## B10 存档 `.psave`（§7.3）

- [ ] `.psave` 存：已学技能栏/背包与穿戴/加点与剩余点/已揭晓奖励/骰子结果/位置/身上状态
- [ ] 导入/导出两份文件；多周目重开
- [ ] **组件库单独导入/导出**（整个库存成文件带走，跨设备同步，§7.3）
- [ ] `.pmod` 加 `version` 字段（格式迁移钩子）

## B 验收

- [ ] 1. 默认 `/` 进游玩；`/build` 进构建；两路由同应用
- [ ] 2. 加载 `.pmod` 能开局：职业随机/固定、加点界面、保底对、家当正确
- [ ] 3. 移动：正交/不可斜走/原路返回；走 N 步只 tick 一次；用道具不 tick（决策 6）
- [ ] 4. 战斗两回合结构：玩家点攻击→怪物反击；落空仍反击；**击杀怪物即时结束不反击**（决策 5）
- [ ] 5. **tick 前移验证**：1 滴血中毒，回合开始先判血(存活)再 tick(扣到0)，本回合可吃药救活（决策 6）
- [ ] 6. 死亡不对称：玩家 hp≤0 回合开始才死（有缓冲）；怪物即时死
- [ ] 7. 玩家"不防御"走固有数值（非0）；怪物始终掷 def_roll；无倒计时（决策 12）
- [ ] 8. 电脑掷骰全公示；力值链五环明细可见；mp 流水可见
- [ ] 9. 技能 6 步：cost 不足置灰；self 不对抗仍掷骰；仅命中执行 effects
- [ ] 10. 状态闭环：挂→每回合开始 tick→解毒剂解→到点消失；本回合新状态下回合才 tick
- [ ] 11. 事件/商店/战利品跑通；货币只是一件道具；事件必成/必败提示
- [ ] 12. 装备穿戴/消耗品/背包上限生效
- [ ] 13. `.psave` 存读正确；组件库单独导入导出；多周目
- [ ] 14. 选怪/属性骰：每次遭遇实例化摇一次、同怪整场不重摇、不同遭遇各自独立摇（决策 2）
