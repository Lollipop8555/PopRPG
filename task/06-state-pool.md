# V2.3 — 全局状态池（跨 A / B）

> **里程碑范围**：三类型与读写算子 / `.pmod` 顶级段 `## Pool`（`pool` ＋ `conds` ＋ `checks`）的解析与导出 / **双空间前缀隔离** / **存储不分空间 ＋ 读写接口按 `space` 参数化** / **主角六维属性并入与旧存储退役** ＋ **引擎变量扩充（累计步数 / 位置 / 道具件数 / 货币走预设道具）** / 工程持久化与撤销登记 / 运行时播种与求值 / **判定两类（回合判定 ＋ 触发判定）** / **对话 if-else 与门锁接入** / **判定模板（命名条件 `conds`）** / **一次性对话预设（引擎不再内建对话记账）** / **键对键比较（`ref`）** / **观察登记** / **状态池定义面板（表格 ＋ 「引擎」tag 内置变量清单 ＋ 自动推荐 ＋ 自动收录 ＋ 判定模板页签 ＋ 回合判定页签）** / 校验 `K20`–`K37`。
> **上层索引**：[`../TASK.md`](../TASK.md)　**设计依据**：[`../docs/design/state-pool.md`](../docs/design/state-pool.md)（**唯一权威口径**，全文）、[`../docs/design/01-pmod.md`](../docs/design/01-pmod.md) §3.1、[`../docs/design/04-editor.md`](../docs/design/04-editor.md) §5.4 G7 / **§5.8**、[`../docs/design/07-decisions.md`](../docs/design/07-decisions.md) §8.5 **裁决 31–60**。
> **前置与优先级**：**结构改造类追加设定，与 V2.0 同档**；**档位与优先级已定稿（裁决 50，`SP-1` 收口）**：记为 **V2.3**，**紧随 V2.0、排在 V2.1 收尾与 V2.2 之前**（结构改造先做、避免皮肤返工）。**无前置阻塞**——编辑器侧（S0–S2 / S5）只依赖已完成的 Phase A，运行时侧（S4 / S6 / S7）只依赖已完成的 Phase B 与 V2.0 对话弹层。本引擎**无存量用户**，故**直接重写数据结构**，不做旧档迁移（只做读取容错）。
> **纪律**：① **读与写是两个维度**——写算子**无返回值**，`if (set(...))` 这类写法在设计上不存在（裁决 35）；② **`.pmod` 的声明一律强制补 `usr-`**，`engine-aaa` 亦落为 `usr-engine-aaa`，作者**不可能**声明或覆写 `engine-` 键（裁决 32）；③ 池**不判定通关、不产生结局**（裁决 38），与 `Rules.state`（状态效果）**并存、互不替代**；④ 任何交互必须能在 §5.4 或 **§5.8** 找到出处，找不到先改文档再加代码；⑤ **依赖只能指向有别名者**，批内**匿名回合判定永远最后执行**，**缺依赖仅忽略该条、本条照常执行**（裁决 42）；⑥ **回合判定按来源自然排序**——`pmod` 业务 → `state` buff tick → **`engine` 内置基础判定（存活 / 死亡）强制最后**（裁决 47）；⑦ **判定模板与变量共用命名空间**，且**不支持模板引用模板**（条件里只能引用变量与字面量，裁决 53）；⑧ **交付验收口径 `psave` ＝ 状态表**——池之外不再有第二份可变状态，对话进度 / 一次性标记一律迁入池（裁决 54 / 55）。

## S0 类型与算子（`state-pool.md` §一 / §四 / §五）

- [ ] `PoolType = 'string' | 'number' | 'boolean'`（**没有第四种**，无数组与对象）
- [ ] `PoolValue = string | number | boolean`
- [ ] **两套算子字面量联合，互相不可混用**：`PoolReadOp`（`equals` / `notEquals` / `greater` / `less` / `greaterEqual` / `lessEqual` / `contain` / `notContain`）与 `PoolWriteOp`（`set` / `append` / `add` / `minus` / `multiply` / `divide` / `toggle`）
- [ ] `PoolVar { key?: string; name: string; type: PoolType; value: PoolValue; desc?: string }`
- [ ] `CondTpl { key?: string; name: string; desc?: string; when: PoolCheck }`（**判定模板** `conds`；**没有 `type` / `value`**，与变量**共用命名空间**（同名出 `K36`），**不支持模板引用模板**）
- [ ] `PoolEffect { name: string; op: PoolWriteOp; value: PoolValue }`（**无返回值**，不参与判断）
- [ ] `PoolCondItem { name: string; op: PoolReadOp; value?: PoolValue; ref?: string }`——`value` 与 `ref`（**键对键比较**，另一池键的规范全名）**二选一**；同时写则出 `K37`、运行时只认 `ref`（裁决 58）
- [ ] `PoolCheck { mode?: 'all' | 'any'; items: PoolCondItem[] }`（空集合**视为成立**）
- [ ] `PoolRoundCheck { alias?: string; deps?: string[]; when: PoolCheck; pool: PoolEffect[] }`（**回合判定**；`alias` 省略 ＝ 匿名，**不可被依赖**；`deps` **可多条**；运行期另标 `source: 'pmod' | 'state' | 'engine'`，**非 `.pmod` 字段**，用于来源分批排序）
- [ ] `PoolIndex`／**声明登记表**（**派生、供类型解析 / 写权限 / 编辑器与 `K20` 比对**）：`Map<name, { space: 'engine' | 'usr'; type: PoolType; value: PoolValue; source: 'engine' | 'pmod'; writable: boolean }>` —— 引擎键与作者键**同表**；**它不是读接口的前置**（读接口只按 `space` 拼前缀查扁平表，§2.5）
- [ ] `PoolWatch`（**派生、不落盘**）：`Map<name, 使用处[]>` 反查表，由各使用处的 `if` / `pool` 引用键推导（§6.5）
- [ ] 类型守卫：算子在给定声明类型上是否**适用**（供 `K26` 与自动收录的类型推断共用）
- [ ] 单测：算子适用性矩阵（三类型 × 两套算子）、空判定成立、除数为零拒绝

## S4 运行时（§八）

- [ ] 池持有形态：**一局一份**的扁平纯数据对象（`Record<规范全名, value>`），`engine-` 与 `usr-` **同容器、不分空间**；**读写接口 `read(space, key)` / `write(space, key, op, value)` 按 `space` 自动追加前缀**；另建**声明登记表**与**观察反查表**两张派生结构（读档后重建）
- [ ] **开局播种**：先播引擎空间（按职业 `base_stats` ＋ 分配点算六维与上限，`hpValue` / `mpValue` 取满值；`engine-steps` 置 0、`engine-pos` 置起点串、按 `starting_items` 汇总 `engine-item.*`，再写其余引擎键），再播作者空间（按 `## Pool` 的 `pool` 逐条写入 `value`）
- [ ] **回合开始时序（来源分批，§8.3）**：① `pmod` 业务判定 → ② `state`（既有 `Rules.state` 的 `per_turn` 与 `duration -= 1`） → ③ **`engine` 内置基础判定（存活 / 死亡，强制最后）**；**无独立"存活判定第一 / 状态 tick 第三"三段**
- [ ] **回合判定的排序（§8.4）**：**先按 `source` 分三批**（`pmod` → `state` → `engine`）；**每批内**：有 `alias` 者按 `deps` 建图 → **稳定拓扑排序**（Kahn，入度 0 者按声明顺序出队）→ **匿名判定按声明顺序追加在该批末尾** → 成环则按声明顺序兜底；**`deps` 指向不存在 / 无别名的判定 → 该条依赖不成边、本条照常执行**
- [ ] **求值顺序（触发判定）**：进入建筑 → 门锁判定 → NPC 对话（逐层按求值方式选记录 → 展示 → `give` → `pool` → `items`）；踩道路格 → 门锁判定排在既有 `tags` 判定之后、`missing` / `penalty` 之前
- [ ] **观察通知（§8.5）**：写算子落到某键 → 查反查表 → 把登记了该键的使用处标为需重算；**正在展示者即时重算当前层**
- [ ] 修改**立即生效**（同帧后续读取即可见），故"先写再判"在同一层即可完成
- [ ] 判定与修改**不产生提示浮条**（状态变化不是财物交割）
- [ ] **存档**：`.psave` 与浏览器状态存储**以池为状态容器**（引擎空间 ＋ 作者空间）；**验收口径 `psave` ＝ 状态表**——池之外不再有第二份可变状态（对话进度 / 一次性标记 / 抽定的 NPC / 方案一律入池，裁决 54 / 55）；纯数据、无特殊序列化；读档即整体替换；老档不迁移
- [ ] 单测：播种、写后即读、门锁拦截、拓扑排序（稳定 + 匿名后置 + 成环兜底）、观察通知、存档往返

## S5 编辑器面板（**§5.8**）

- [ ] 入口在**编辑模式工具栏**（与「NPC 模组」同级）→ **单独弹出对话框面板**，**不占画布模式条**（G7）；面板分**「变量表」「判定模板」「回合判定」三页签**
- [ ] 变量表主体为表格：`key` / 说明（`desc`） / 类型（三选一） / **引用数**（**派生统计、不落盘**） / **空间 tag**
- [ ] **内置变量清单并列展示**：按 §三 总表逐行列出 `engine-` 变量，打 **「引擎」tag 且只读**；作者行打「作者」tag 可编辑；提供"只看作者 / 只看引擎 / 全部"筛选与关键词搜索
- [ ] 支持**添加**与**删除**（仅作者行）；删除仍有引用的键时**提示引用处数并要求确认**，**不自动清理引用**
- [ ] 改类型时**同时校正默认值**（否则 `K24`）；短名含 `-` 或为空 → `K27`；重名 → `K21`
- [ ] **判定模板页签**：列出 `conds` 每一条（短名 / 说明 / 条件，与回合判定同一套控件）；**起名时即时比对变量表、重名标红**（`K36`）；显示**引用数**，删除仍有引用的模板时提示处数并要求确认（引用处此后出 `K35`）；**引用了另一个模板名即标红**（不支持模板引用模板）；各使用处条件栏提供**「转存为模板」**
- [ ] **回合判定页签**：逐条填别名 / 依赖（下拉**只列已有别名**）/ 条件 / 动作；有名判定按拓扑序显示执行序号，匿名归入「匿名（最后执行）」区；提供**依赖图**小视图；**成环标红并给出环路、禁止保存 / 导出**（`K30`）
- [ ] 面板改动**计入一步撤销**，并随当前工程持久化
- [ ] **自动推荐**：对象设置面板输入关键词即推荐相关变量（按短名与说明前缀匹配），**跨两个空间列出（含内置变量联想）**；选中引擎空间的键时该栏**锁定为只读选择**，并提示该键写权限
- [ ] **自动收录**：输入**不存在**的短名 → 标 **`new`**，保存该对象时**自动收录**进池；类型由该处算子推断（`greater` → `number`；`contain` → `string`；`toggle` → `boolean`；无法推断默认 `number`），默认值取零值；**只进作者空间**，`engine-` 的未知名字**不收录**
- [ ] 单测：表格增删、引用数统计、自动收录的类型推断与去重、删除时的引用提示、引擎行只读、拓扑序展示、回环阻断

## S6 判定机制（§五 / §八）

- [ ] **回合判定**：每回合开始执行一次；`.pmod` 的 `checks` 集中声明；`when` 成立才执行 `pool`
- [ ] **触发判定**：事件触发时就地内联（对话 `if` / 门锁 `pool` / 建筑触发），无别名、不参与排序
- [ ] **别名与依赖**：只有 `alias` 非空的判定可被 `deps` 指向；`deps` 只列已有别名（编辑器从源头限制）
- [ ] **拓扑排序（逐批）**：**先按 `source` 分三批**（`pmod` → `state` → `engine`）；批内稳定排序（同层按声明顺序）；**匿名判定后于本批有名判定**，按声明顺序追加
- [ ] **回环**：编辑器警告 + **禁止保存 / 导出**（`K30`）；手写文件按声明顺序兜底、不卡死
- [ ] 单测：排序稳定性、匿名后置、成环检测与兜底、`deps` 指向不存在 / 匿名者（`K28` / `K31`）

## S7 使用处接入与校验（§六 / §十）

- [ ] **对话记录新增两项**：`pool`（修改动作，与 `give` 同级并列，**先结算 `give` 再执行 `pool`**）与 `if`（状态判定，**if-else 链、允许嵌套**；手写 `when` 读作单分支 `if`）
- [ ] **if-else 求值（同层三选一）**：本层不含 `if` 且不含 `dice` → 顺序展示；含 `if` → **自上而下取第一条成立者、命中即停**，末尾无 `if` 记录 ＝ `else`，无命中即本层结束；含 `dice` → 既有 `dice` / `hit` 口径
- [ ] **同层 `if` 与 `dice` / `hit` 二选一**（混用出 `K33`，运行时以 `if` 优先）
- [ ] **门锁 `Gate` 新增 `pool`**（与既有 `tags` **同档并列**，两者都要满足才放行；`mode` 沿用既有口径）；落点即既有落点，**不新增使用位置**
- [ ] **建筑触发判定**：`encounter` 前置可带 `pool` 判定（与门锁同构）
- [ ] **判定模板引用**：使用处的 `if` / `pool` 判定位置可直接写**模板名**（条件体与模板名二选一）；**未声明的模板名出 `K35`**（运行时该条件**恒不成立**），编辑器提供"补一条模板"快捷操作
- [ ] **键对键比较（`ref`）**：条件项的右值可为**另一池键的规范全名**（`ref`）；`value` 与 `ref` 同写出 `K37`（只提示），运行时**只认 `ref`**；`ref` 指向的键须已声明（否则 `K20`）
- [ ] **一次性对话预设**：实例页「一次性对话」勾选 → 自动写出"一条作者标记 ＋ 一条模板 ＋ 首层 `if`"（引擎不再内建 `retalk` / 进度标记；**重入不再弹框**，进入即按对话树求值，裁决 54）
- [ ] 校验 `K20`–`K37` 全部落地（引用未声明 / 重复声明 / 除数为零 / 写只读引擎键 / 默认值与类型不符 / 空判定 / 算子与类型不符 / 短名非法 / 依赖别名不存在 / 别名重复 / **依赖成环** / 依赖匿名判定 / 道具 id 不存在 / 同层 `if` 与骰子混用 / 无效 `else` 位置 / **判定模板未声明** / **模板名与变量短名重名** / **`value` 与 `ref` 同写或类型不符**），除 **`K30` 阻塞**外**只提示、不阻塞**，并**纳入「清单」汇总视图**
- [ ] `K20` 提供"补一条声明"快捷操作；未声明的 `usr-` **不拦截保存与导出**
- [ ] 单测：if-else 链（命中即停 / else / 嵌套 / 无命中结束）、`if` 与 `dice` 混用提示、门锁 `pool` 与 `tags` 的合取、各校验各自触发
