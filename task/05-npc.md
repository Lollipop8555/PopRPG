## E0 数据模型与类型（§4.9 / §4.4）

- [ ] `NpcDef`：`EntityBase`（`id` / `name` / `icon` / `tags` / `desc`）＋ `dialogs: Record<string, DialogNode[]>`（**方案名 → 根节点数组**）
- [ ] `DialogNode { result?: string; message: string[]; dice?: Dice; items: DialogItem[] }`；`DialogItem` 为 **`chat` / `prop` 二选一的判别联合**：`{ type:'chat', hit?: string, result, message, items }` / `{ type:'prop', hit?: string, result, items: string[] }`
- [ ] `Rules` 新增 `talk: { dice: Dice }`（缺省 `1D6`）；`DEFAULT_RULES` 同步，**配置项总账 13 → 14 项**（§4.8.6）
- [ ] 建筑行为 `encounter` 由五选一扩为**六选一**（新增 `talk`）；**建筑实例（地图节点）新增可选字段 `npcs?: string[]` / `dialog?: string`**（位置写在节点上，不写进建筑定义）
- [ ] `.pmod` 解析 / 导出：`### NPC` 段解析 `dialogs` 嵌套对象（含节点 `dice` / 项 `hit`）、地图节点解析 `npcs` / `dialog`；含回边、`prop` 与 `chat` 混排、`hit` 无所属（父节点无 `dice`）等非法结构按 §4.9.2 容错并在清单提示（**`hit` 无所属时导出剔除**）
- [ ] 单测：对话树校验（空对话 / 悬空 `prop.items` / 混排 / 回边 / `hit` 覆盖与重叠）与 `Rules.talk.dice` 解析

## E2 NPC 模组面板（§5.6.1，思维导图）

- [ ] 顶栏新增**整页入口「NPC 模组」**（与「规则」并列的第二个整页）：**不进右栏、不占画布模式条**（G7）
- [ ] 左侧 NPC 列表（只列本局**被引用**的 NPC，带 `被引用 ×N`）；右侧思维导图画布
- [ ] 方案下拉（`Mod1` / `Mod2` …）＋ 新建 / 重命名 / 删除；**面板不写权重**（多套方案等权）
- [ ] 节点卡片：**节点标题 `result`（可省）** ＋ `message` 多行台词列表（一行一条、可拖动排序）＋ 选项列表（每行一个 `chat` 项的 `hit` / `result` 与其中台词）
- [ ] 节点顶部 **`dice` 下拉**（如 `1D6`，默认「无」）：**填了 → 该层选项改为掷骰命中**，各选项行出现 `hit` 区间输入框；**选「无」→ 回到直接点选**，`hit` 输入框隐藏并在导出时剔除（§4.9.2）
- [ ] **命中覆盖检查（只提示不拦截）**：节点填了 `dice` 后实时统计各 `hit` 的并集，标出**未覆盖点数**（"掷到 `4` 无选项命中，运行时会要求重掷"）与**重叠**（"`3` 同时命中 A 与 B"）；**不阻止保存 / 导出**（§5.7）
- [ ] 连线 ＝ 父子关系：从卡片**底部端口**拖到目标卡片；**拖向自身或祖先时拒绝并提示**（树不能有回环）
- [ ] 「＋ 给道具」新增 `prop` 项：**道具多选**、**同一道具可重复添加 ＝ 多份**；该节点即成为对话终点，**UI 不再允许从它继续连线**
- [ ] 断开连线：移除该父子关系，**子孙节点保留在画布上**，不静默删除内容
- [ ] 删除节点 ＝ 连同其子树，先提示「将删除 N 个后续节点」
- [ ] 撤销 / 重做与构建页**同一撤销栈**；整棵树的增删改各算**一步**
- [ ] 折叠卡片子树（**只影响显示**，不影响导出）；平移 / 缩放锚点跟随光标（与 §5.5 一致）
- [ ] 「给道具」下拉**只列已启用道具**；引用失效时按 §5.7 标红

## E3 建筑实例页与校验（§5.6 / §5.7）

- [ ] 建筑定义 `encounter: talk` → 组件页**只显示指路** ＋ `[去实例页配置]` 按钮（**不在定义里配 NPC**）
- [ ] 实例页（仅当该建筑是 `talk`）：`npcs` 候选列表（下拉只列库里的 NPC，可增删）＋ **概率旁注**——留空 ＝ 没有对话 / 1 位 ＝ 必定遇到 / 多位 ＝ 掷 `talk.dice` 等权抽一位
- [ ] 实例页 `dialog` 方案下拉：列出所选 NPC 的**全部方案**；**留空 ＝ 多套时掷骰**（只有一套时面板直接写明必定用它）；**选中某方案名 ＝ 写死、不掷骰**
- [ ] 规则面板新增 `talk.dice`（对话骰）＋ 旁注 ＋「模拟 10 次」
- [ ] 「清单」新增校验项：说 `talk` 却没配人（标黄）/ 挂了 NPC 却不是对话建筑（标红 ＋ `[改成 talk]` 快捷修复）/ 空对话（标黄）/ 道具结局悬空（标红）/ `prop` 与 `chat` 混排（标黄）/ **命中覆盖不全（标黄、不拦截）** / **`hit` 重叠（标黄）** / **`hit` 无所属（标黄、导出剔除）** / **`hit` 越界（标红）** / 多套方案未写 `dialog`（**提示将由骰子抽取，不算错误**）
- [ ] 引用完整性：`npcs` 只能指向**库中存在的** NPC（**无「启用」要求**）；`prop.items` 只能指向**已启用**道具

## E4 运行时：NPC 触发与对话弹层（**进入建筑后、建筑事件之前**）（§4.9.3 / §7.6，接 B7）

- [ ] 踩到 `encounter: talk` 的建筑实例：按 `npcs` 长度决定——**空 ＝ 等同 `empty`**、**1 位 ＝ 直接取**、**多位 ＝ 掷 `talk.dice` 等权抽一位**
- [ ] 选方案：`dialog` 写死则跳过该步；否则该 NPC 方案数 ＝ 1 直接取、**> 1 掷 `talk.dice` 等权抽一套**（写不存在的方案名按悬空引用降级为掷骰）
- [ ] **两级各掷一次、踩到抽定、整场不重掷**（与怪物登场掷骰同一原则，抽取结果存入 `.psave`）；**掷定即锁死**——重踩 / 回访不再重掷、不换人、不换方案（锁在建筑实例）
- [ ] **`npcs` 与 `encounter` 正交**（V2.0 追加设定）：实例没写 `npcs`（或写空数组）→ **不触发对话**、直接跑该建筑的 `encounter`；定义是 `talk` 但没写 `npcs` → **既无建筑事件、也无对话**（等同 `empty`）；实例写了 `npcs` 而定义**不是** `talk` → **照样生效**（先对话、再跑建筑事件），**不提示、不拦截**
- [ ] **只在「进入建筑」时触发一次**：**从建筑外踏入该建筑任意一格**算进入；**建筑内部走位不再触发**（多格建筑是同一座、同一节点 key）；**首次进入一定进对话**
- [ ] **重入先弹「选择对话框」**：该实例已触发过对话 → 再进入**不直接进对话**，先列**已锁定的那位 NPC 的名字**（点它 ＝ **重看**；**已交付**的实例只回放交付节点台词）＋「**直接进入**」（跳过对话，直接跑建筑事件）；**不换人、不重掷**
- [ ] **空宝箱 ＋ NPC 不算空**：`treasure` 没配奖励池（或抽到 0 件）**但配了 NPC** → **不输出"什么也没有 / 已经空了"**，直接走对话
- [ ] 对话弹层：顶部 **VS 立绘区** ＋ 台词区（`message` **逐条展示**、点击「继续」推进、**不做打字机 / 逐字动画**）＋ 选项区
- [ ] **节点选项抽取**：节点带 `dice` → 选项区显示**「掷骰」按钮**（而非选项列表），掷出点数按各 `hit` 区间命中——**未命中任何 `hit` 就再给一次掷骰**，直到命中；节点无 `dice` → 显示**可点的选项列表**（§4.9.2）
- [ ] `prop` 结局：结算给出的道具（按 `items` 重复次数计份数），受 `inventory_size` 约束（满则拒绝并提示），随后对话结束
- [ ] **`prop` 一次性交付（终态）**：交付后把"该实例对话已交付 + 交付节点"写入 `.psave`；再次进入**只回放该交付节点的 `message`**，**不再出 `items` / 不再给道具**（防刷）
- [ ] 对话**不判定、不给属性点、不写剧情旗标**；关闭弹层回到地图
- [ ] 本次抽取结果（哪位 NPC / 哪套方案）按 §7.2 公示口径可查看

## E 验收（原子项）

- [ ] 1. 组件库出现第 9 区 `NPC`；NPC 无「启用」开关；未引用的 NPC 行降透明
- [ ] 2. 组件页能编辑 NPC 基础字段、看到 `dialogs` 摘要，`[编辑对话]` 可跳转模组面板
- [ ] 3. 模组面板能新建方案 / 新建节点 / 连父子 / 加 `chat` 选项 / 加 `prop` 结局；拖向自身或祖先被拒绝
- [ ] 4. `prop` 结局所在节点不能继续连线；同种道具添加两次，导出后确为两份
- [ ] 5. 节点可设 `dice` 并为各选项填 `hit`；**覆盖不全 / 重叠 / 越界时给提示但不阻止保存与导出**；节点无 `dice` 时 `hit` 被隐藏且导出剔除
- [ ] 6. 建筑实例页能选 NPC（0 / 1 / 多）与方案；概率旁注随 `talk.dice` 与候选数变化
- [ ] 7. 导出 `.pmod` 后重新导入，对话树（含 `dice` / `hit`）与 `npcs` / `dialog` 完全一致（回归项）
- [ ] 8. 游玩时踩到 `talk` 建筑：候选多位时抽一位、方案多套时抽一套；**同一实例整场重踩不变（掷定即锁死）**
- [ ] 9. 台词逐条展示、点击继续；节点无 `dice` 时选项可点、点击后进入对应分支；节点有 `dice` 时给「掷骰」按钮并按 `hit` 命中，**未命中可再掷**
- [ ] 10. `prop` 给出道具并结束对话；**再次对话只回放交付节点的 `message`、不再给道具**（终态）
- [ ] 11. 背包满时 `prop` 给道具被拒绝并提示，对话仍正常结束
- [ ] 12. 新增校验依次触发（无对话标黄 / **非 `talk` 建筑挂 NPC 不再报错（正交）** / 空对话标黄 / 道具悬空标红 / 混排标黄 / **命中覆盖不全标黄不拦截** / **`hit` 重叠标黄** / **`hit` 无所属标黄并剔除** / **`hit` 越界标红** / 多方案未写 `dialog` 提示 / **空宝箱 ＋ NPC **不**报"空的"，空宝箱且无 NPC 标黄**）
- [ ] 13. 对话全程**不产生结局、不写旗标、不改变通关条件**
- [ ] 14. **进入 / 重入**：只在**从建筑外踏入**时触发一次（**建筑内部走位不触发**）；**首次进入一定进对话**；**再入先弹选择对话框**（点 NPC 名字重看 / 选「直接进入」跑建筑事件）
- [ ] 14. 规则面板出现 `talk.dice`，清单字段数与 §4.8.6 的 **14 项**一致
- [ ] 15. `npm run build`（tsc 无错）＋ `npx vitest run` 全绿
