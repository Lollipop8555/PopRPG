## E4 运行时：NPC 触发与对话弹层（**进入建筑后、建筑事件之前**）（§4.9.3 / §7.6，接 B7）

- [ ] **触发主体是建筑实例、不是建筑定义**：踩到**任意建筑实例、且该实例 `npcs` 非空** → 按进入判定（下一项）后抽人：**1 位 ＝ 直接取**、**多位 ＝ 掷 `talk.dice` 等权抽一位**；`npcs` 空 → **不触发对话**（**不是**"等同 `empty`"），直接跑该建筑的 `encounter`（正交口径）
- [ ] 选方案：`dialog` 写死则跳过该步；否则该 NPC 方案数 ＝ 1 直接取、**> 1 掷 `talk.dice` 等权抽一套**
- [ ] **`dialog` 方案名悬空 → 跳过对话、当该实例没有 NPC**：实例写的方案名**不在所抽到 NPC 的 `dialogs` 里** → **不进对话、不阻住建筑事件**（直接跑 `encounter`）；**导出【不剔除】该字段**（剔除会把它变成"留空 → 掷骰"，语义正好相反）；编辑器标红 ＋ 进「清单」（§8.3 设定 5）
- [ ] **两级各掷一次、踩到抽定、整场不重掷**（与怪物登场掷骰同一原则，抽取结果存入 `.psave`）；**掷定即锁死**——重踩 / 回访不再重掷、不换人、不换方案（锁在建筑实例）
- [ ] **`npcs` 与 `encounter` 正交**（V2.0 追加设定）：实例没写 `npcs`（或写空数组）→ **不触发对话**、直接跑该建筑的 `encounter`；定义是 `talk` 但没写 `npcs` → **既无建筑事件、也无对话**（等同 `empty`）；实例写了 `npcs` 而定义**不是** `talk` → **照样生效**（先对话、再跑建筑事件），**不提示、不拦截**
- [ ] **只在「进入建筑」时触发一次**：**从建筑外踏入该建筑任意一格**算进入；**建筑内部走位不再触发**（多格建筑是**同一个节点**，靠 `w` / `h` 覆盖多格）；**首次进入一定进对话**
- [ ] **首次进入不弹框、重入先弹「选择对话框」**：该实例已触发过对话 → 再进入**不直接进对话**，先列**已锁定的那位 NPC**（**不换人、不重掷**）＋ 按标记给动作（§8.3 设定 3、§4.9.2）：
  - **未走完**（`talkDone` 假）→【**继续对话**】＝ 回到 `cursor` 节点接着走（**没有 `cursor` 就从根节点开始**，这一层的 `dice` 重新掷）、【**重新对话**】＝ 丢弃进度、从根节点**完整重播**
  - **已走完**（`talkDone` 真）→ 上面两个 **＋【路过】**（＝ 跳过对话，直接跑建筑事件）
  - 【继续】在**已交付**时只回放 `deliveredNode` 的 `message` 后结束；【重新】**不重置** `talkDone` / `deliveredNode`——**已交付的实例不会再发一次道具**（防刷）
- [ ] **空宝箱 ＋ NPC 不算空**：`treasure` 没配奖励池（或抽到 0 件）**但配了 NPC** → **不输出"什么也没有 / 已经空了"**，直接走对话；对话结束后**照旧执行该建筑的 `encounter`**（`treasure` 空池 → 无产出、同样不报"空的"）
- [ ] **`.psave` 新增对话字段**（§7.3，登记到 [`02-play.md`](./02-play.md) B10）：按**建筑实例 key** 存 `{ npc, dialog, cursor?, talkDone?, deliveredNode? }`——**抽定结果（`npc` / `dialog`）＋ 三个进度标记**，供「是否触发过 / 重入弹哪几个选项 / 不重掷 / 不重复交付」判定：
  - **`cursor` ＝ 当前停留节点**（从根节点起算的下标路径，如 `[0,2]`）：**每进入一个节点就更新**；**没有它 ＝ 没有进度**（旧档缺字段同样视为没有）
  - **`talkDone` ＝ 对话走完过一次**（走到 `prop` 结算、或走到 `items: []` 的正常结尾）
  - **`deliveredNode` ＝ 已交付的 `prop` 节点**（存在 ＝ 这件东西已经发过了），**与 `talkDone` 分开记**
  - **key 统一为 `<地图名>#<ref>@<锚点>`**：**一座建筑 ＝ 一个节点**（多格靠节点自带的 `w` / `h` 覆盖，**缺省 1**；`road` / `start` / `end` 恒 1×1），**锚点 ＝ 节点自己的坐标 `(x, y)`**——多格建筑只有这一个坐标，从它任意一格进入都是**同一座**；**紧挨着放的两座同名建筑是两个节点、两座**（各记各的，**不按"相邻同种"聚合**）；`ref` 的稳定靠 **"组件 id 不做顺序编号"**（永不变、删除不回收、新增不复用，[`../docs/design/01-pmod.md`](../docs/design/01-pmod.md) §3.2）（§8.3 设定 6）
  - **弱引用**：`.pmod` 改动（`ref` / 坐标 / 地图名）导致 key 不匹配 → 该实例对话状态**视为未触发**（**不报错、不做迁移**），存档里的**孤儿 key 忽略**；**旧存档缺该字段 → 同样视为未触发**
- [ ] 对话弹层：顶部 **VS 立绘区** ＋ 台词区（`message` **逐条展示**、点击「继续」推进、**不做打字机 / 逐字动画**）＋ 选项区
- [ ] **节点选项抽取**：节点带 `dice` → 选项区显示**「掷骰」按钮**（而非选项列表），掷出点数按各 `hit` 区间命中——**未命中任何 `hit` 就再给一次掷骰**，直到命中；节点无 `dice` → 显示**可点的选项列表**（§4.9.2）
- [ ] `prop` 结局：结算给出的道具（按 **`give`** 重复次数计份数），受 `inventory_size` 约束（满则拒绝并提示），随后对话结束
- [ ] **`prop` 一次性交付（终态）**：交付后把 **`deliveredNode`**（＋置 `talkDone`）写入 `.psave`；此后**继续 / 重新都只回放该交付节点的 `message`**，**不再出选项 / 掷骰按钮、不再给道具**（防刷）
- [ ] **三个标记的写入时机**（§4.9.2 / §4.8.12）：每进入一个节点 → 更新 `cursor`；走到 `prop` 结算或 `items: []` 的正常结尾 → 置 `talkDone`；`prop` 结算的同时写 `deliveredNode`；**【重新对话】只把 `cursor` 拉回根节点，不动另外两个标记**
- [ ] 对话**不判定、不给属性点、不写剧情旗标**；关闭弹层回到地图
- [ ] 本次抽取结果（哪位 NPC / 哪套方案）按 §7.2 公示口径可查看
